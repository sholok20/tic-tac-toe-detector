# Tic-Tac-Toe X/O Detection using OpenCV

A Digital Image Processing project that uses OpenCV to automatically detect the X and O symbols on Tic-Tac-Toe boards.

The program processes the provided dataset of Tic-Tac-Toe images, identifies the Xs and Os, determines their positions on the board, and produces annotated images with:

🔴 Xs circled in red
🟢 Os circled in green
📍 The corresponding board positions for each detected symbol

# Board Positioning

Each Tic-Tac-Toe board is divided into nine numbered positions:

        Tic-Tac-Toe Board

        1 │ 2 │ 3
       ───┼───┼───
        4 │ 5 │ 6
       ───┼───┼───
        7 │ 8 │ 9

For example:

Xs Positions → [3, 4, 5]
Os Positions → [1, 2]


X is located in cells 3, 4, and 5
O is located in cells 1 and 2
